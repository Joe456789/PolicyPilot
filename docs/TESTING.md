# 本機測試清單(初賽前自己玩一遍)

啟動:`npm run build` → `PORT=8090 npm run server`(要用 `npm run server`,才會讀 `.env` 開啟 AI),瀏覽器開 `http://localhost:8090`,按 Ctrl+F5。
測試時開 F12 → Console,看有沒有紅色錯誤;有的話把訊息貼給我。

## A. 一定要走一遍的主線(約 15 分鐘)
- [ ] 標題頁 → 開始新的人生 → 隨機外型、隨機名字 → 「從出生開始」
- [ ] 成長篇:年齡動畫(0→3→6…)有跑、事件卡有插圖或表情符號、選項有結果頁;玩到 21 歲選職業
- [ ] 畢業後進棋盤:第一次出現新手教學(10 步),可略過
- [ ] 開局規劃:買 2~3 種保險、看「教練提示」、切到理財 / 資產 / 貸款分頁
- [ ] 擲骰子:骰子不被中央高塔擋住、鏡頭先看骰子再跟著棋子、走完回到全景
- [ ] 各種格子至少遇到一次:生活事件、機會卡、市場行情、人生里程碑、小遊戲、理專、銀行、商城、稅務、醫院、**地產格(買 / 貸款買 / 不買)**
- [ ] 買到地產後:左側「我的資產格」、棋盤上建築標記、年底租金、規劃面板「資產」分頁(升級 / 投保 / 賣出)
- [ ] 電腦對手:排名更新、動態欄的對話、他們踩到你的地要付過路費
- [ ] 年度結算視窗的數字(租金、保費、損失)看得懂
- [ ] 玩到結算頁:結局圖、分數、時間軸播放、成績卡產生與下載、PDF 學習報告(Ctrl+P 或按鈕)、成就彈出

## B. 要刻意測的特殊情況
- [ ] **破產**:不買保險、狂借錢、買貴的地產,看會不會被拍賣並出局
- [ ] **住院**:健康低時走到醫院格,接下來回合按鈕變成「住院休養」
- [ ] **30 歲 / 40 歲開局**:創角選年齡 → 開局規劃最上面有「你的起點」說明
- [ ] **手牌**:抽到卡後左側面板出現,事件發生時自動生效
- [ ] 設定面板:深色 / 淺色、介面大小、音量、減少動畫、色盲配色、動漫風格開關、重看教學
- [ ] **深色模式逐畫面看文字有沒有看不見**(含年度結算、結算頁、成就頁、問理專、小遊戲)
- [ ] 2D / 3D 切換;兩種棋盤都是 100 格環島地圖(北中南東 4 區,格子邊框分色),擲兩顆骰子、雙骰會再擲一次,手機直立時地圖會轉 90 度
- [ ] **自動存檔**:玩幾年後重新整理,標題頁出現「繼續上次的人生」,接著玩位置與金額相同
- [ ] **電腦託管**:頂端按鈕選風格與年數,託管中按鈕停用、可隨時「接手」;年數用完會停
- [ ] **資產走勢圖**:規劃視窗「理財」分頁,過一年後出現四條線,點圖看每年報酬,可隱藏資產
- [ ] **人生階段**:選 40 歲開局或「四十年 / 一輩子」長度;孩子到了年紀會出現「🧭 人生階段」(上學、上大學、獨立…),65 歲退休後收入變成年金,左側標籤顯示孩子年齡與「已退休」
- [ ] **生活小事**:擲骰的事件結算後,會再跳出 1~2 件「生活小事」要選;扭傷、漏水、擦撞有保險會理賠
- [ ] **生活 / 商店分頁**:左側「買房買車」「商店」快速按鈕;買車後汽車險可加保、賣車後解約;商店每年最多 2 張
- [ ] **點格子看說明**:3D / 2D 棋盤點任何一格,跳出格子說明;資產格有售價、租金、過路費、天災機率、持有人
- [ ] **玩法說明**:標題頁「📖 玩法說明」或設定 →「玩法說明」
- [ ] **3D 畫風**:設定 →「3D 棋盤畫風」切換寫實電影 / 卡通積木,棋子位置不變;寫實模式在你的電腦上順不順(卡的話告訴我,會自動降特效)
- [ ] **展示模式**:標題頁「展示模式」或 `?demo=1`;字幕會隨畫面更換,暫停 / 加快 / 離開可用;結束後出現「重新展示」;不會覆蓋存檔、不計入成就

## C. 手機(Chrome 開 F12 → 裝置工具列 → iPhone 12/13,或直接用手機連同一個區網)
- [ ] 標題頁、創角、成長篇、棋盤、規劃、事件卡、結算頁都沒有橫向捲動
- [ ] 底部「狀態」「排名與任務」抽屜可開關
- [ ] 按鈕夠大、不會點錯

2. Console 的紅字(整段)
3. 畫面截圖
4. 有沒有開瀏覽器擴充功能(Dark Reader 等)

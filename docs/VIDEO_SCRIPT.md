# 初賽展示影片腳本(3 分鐘內)

規定:3 分鐘內的互動原型展示影片,上傳 YouTube 設為「不公開」,繳交網址。
評分(10%)看的是:**清楚展示 AI 與使用者的互動邏輯,並展現產品化後的使用者旅程。**

所以這支影片要讓評審看到四件事:
1. 理專(學員)怎麼一年一年玩下去(使用者旅程)
2. AI 在哪裡出現、做了什麼(Gemini 寫情境、扮演客戶、給教練回饋;自訓練模型預測風險)
3. 數字由規則引擎算,所以可信(理賠、平行人生、對練評分)
4. 產品化之後怎麼導入(前後測、主管後台,對應法巴人壽的銀行通路與房貸壽險業務)

---

## 懶人做法:自動錄影(`npm run record`)

不想自己操作的話,腳本會照下面的分鏡自動操作遊戲、錄成 1920×1080 影片,畫面下方附字幕,開頭與結尾有片頭、片尾卡:

```bash
npm install
npx playwright install chromium   # 下載失敗也沒關係:會改用 Edge 瀏覽器和電腦裡的 ffmpeg
npm run build
npm run server        # 先開著(要讀 .env 的 GEMINI_API_KEY)
npm run record        # 另開一個終端機,會自動讀 .env 的 PORT
```

- 想看到瀏覽器操作:PowerShell 用 `$env:HEADED=1; npm run record`
- 片尾要顯示團隊名稱:`$env:TEAM="你們的隊名"; npm run record`

輸出在 `video/`:
- `保險大富翁_展示影片.webm`(或 `.mp4`):原速完整版(約 3 分 40 秒)
- `保險大富翁_展示影片_3分鐘版.mp4`:電腦託管那段加速 4 倍(約 2 分 40 秒;AI 回應比較慢時會自動加快,確保在 3 分鐘內),沒有聲音。需要電腦裡有 ffmpeg(Windows:`winget install ffmpeg`,裝完重開終端機)
- `保險大富翁_展示影片_3分鐘版_配音版.mp4`:自動把字幕念成旁白,**上傳 YouTube 用這個**。
  - 聲音最好的是微軟自然語音:先裝 Python,再執行 `pip install edge-tts`(要連網)
  - 沒有 edge-tts 就用 Windows 內建語音(要有中文語音,沒有的話到「設定 → 時間與語言 → 語音」新增)
  - 只想重新配音、不重錄:`npm run narrate`;換男聲:`$env:VOICE="zh-TW-YunJheNeural"; npm run narrate`
- 兩個對應的 `.srt` 字幕:匯入剪映 / CapCut 可以直接「文字轉語音」產生旁白
- `學習報告範例.pdf`:錄影時下載的學習報告

## 錄影前準備(自己錄的話)

1. **一定要用接上 Gemini 的本機版**,不要用 GitHub Pages 網頁版(網頁版不呼叫 AI,對練的客戶與教練回饋會是離線規則版本)。
   ```bash
   git pull
   npm install
   npm run build
   npm run server      # 會讀 .env 裡的 GEMINI_API_KEY,打開 http://localhost:8080
   ```
   遊戲頂端的標籤要顯示「✨ AI 已連線」(不是「✨ AI(模擬)」或「離線備援模式」)。
2. **用無痕視窗錄**:遊戲會記住最近兩局出現過的事件,無痕視窗才能保證每次錄到一樣的劇情。
3. 視窗大小 1920×1080,瀏覽器縮放 100%;設定裡選淺色模式、3D 棋盤「寫實電影」畫風、音量開著。
4. 錄影軟體:Windows 可以用 OBS 或 Xbox Game Bar(Win + G)。建議**每一段分開錄**,最後用剪映、CapCut 或 Clipchamp 剪在一起、加旁白和字幕。

**固定劇情的網址**(種子 31、12 年短局、2 位電腦對手、股市照台股 2008 年起的真實行情):

```
http://localhost:8080/?auto=1&seed=31&opp=2&len=short&hist=2008
```

用這個網址,第一次擲骰一定會遇到「意外骨折」事件(AI 會改寫成不同的情境),先買好醫療險就會出現理賠申請;股市第一年是 2008 年金融海嘯、第二年是 2009 年的反彈;第 8 年會有 AI 理專的階段回顧,第 12 年結束看到結算頁。

## 分鏡腳本

旁白語速大約每秒 4~5 個字。時間是 3 分鐘版的建議值,總長控制在 2 分 50 秒以內。

### 0. 片頭卡(0:00–0:04)

**畫面**:綠色片頭卡:「Cardif InsurHack 2026 · 題目 1-1 銷售與通路賦能」「保險大富翁」「理專與通路夥伴的財務人生訓練遊戲」。

**旁白**:
> 保險大富翁:理專與通路夥伴的財務人生訓練遊戲。

### 1. 標題頁(0:04–0:11)

**畫面**:標題頁,滑鼠先指下方的「訓練中心」(AI 客戶對練、10 分鐘情境挑戰、觀念前測、主管後台),再指「開始新的人生」。

**旁白**:
> 理專最難讓客戶懂的,是還沒發生的「萬一」。我們讓理專在遊戲裡,先走完一生。

### 2. 創角 + 前測入口(0:11–0:17)

**畫面**:按「開始新的人生」,滑鼠指「教育訓練用:先做 1 分鐘觀念前測」,再往下捲過個性、志向、開局年齡。

**旁白**:
> 教育訓練時,學員先做一分鐘觀念前測,再建立角色開始玩。

### 3. 年度規劃 + AI 風險預測(0:17–0:38)

**畫面**:打開固定劇情網址。開局規劃視窗出現後:
1. 滑鼠指向「🤖 AI 風險預測」和下面的原因。
2. 在「保障」分頁把**醫療險**選「實支實付」、**重大傷病險**選「100 萬」、**失能所得補償**選「收入 30%」。
3. 風險預測下降,滑鼠圈一下;再指一下「🧠 AI 學習型玩家會怎麼做?」。

**旁白**:
> 每年先規劃保障。右邊是我們自己訓練的機器學習模型,預測未來八年的財務危機機率;補上醫療、重大傷病和失能險,機率馬上下降。

**字幕**:自訓練風險預測模型|準確率 88.6%、AUC 0.87

### 4. 擲骰 + AI 事件導演 + 真實數據卡(0:38–0:57)

**畫面**:
1. 按「完成,去擲骰」,勾選上方的「教練提示」,再按「擲骰子」。
2. 事件卡出現(右上角有「✨ AI 導演」標籤),滑鼠指一下情境下方的「🚑 真實世界的台灣」(交通事故的政府統計)。
3. 滑鼠指著選項下面的教練提示(預估自付、保險賠多少),選第一個選項。

**旁白**:
> 擲骰子遇到事件:Gemini 依角色處境即時寫情境,金額與理賠由規則引擎計算,旁邊還附上台灣政府的真實統計。

**字幕**:AI 寫劇本,規則引擎算帳|事件附台灣政府公開統計

### 5. 理賠申請(0:57–1:10)

**畫面**:結果下方的「📝 申請理賠」。勾選「理賠申請書與存摺影本」「診斷證明書」「醫療費用收據」,按「送出申請」,出現「理賠核准」蓋章動畫。

**旁白**:
> 有保險,還要會申請理賠:學員要自己挑對文件。

### 6. 電腦託管快轉 + 台股真實歷史 + 階段回顧(1:10–1:33,加速)

**畫面**:
1. 處理完這一年的生活小事後,頂端按「快轉」→「電腦託管」→「到結束」→「開始託管」。
2. 頂端會顯示「台股 2008 年」「台股 2009 年」……行情格會出現當年真實的新聞與收盤。
3. 第 8 年跳出 AI 理專的「階段回顧」,按「繼續人生」讓託管繼續。

**旁白**:
> 接著電腦託管快轉。這局選了台股真實歷史,2008 金融海嘯和隔年的反彈都會真的發生;每隔幾年,AI 理專會做一次階段回顧。

### 7. 人生結算 + 學習報告(1:33–1:41)

**畫面**:結算頁的「平行人生」走勢圖,接著按「下載 PDF 學習報告」。

**旁白**:
> 結算時,平行人生用同樣的事件,算出沒保險和建議配置差多少,還能下載 PDF 學習報告。

**字幕**:同樣的人生,只換保障

### 8. AI 客戶對練(1:41–2:14)

**畫面**:結算頁下方按「換你當理專:AI 客戶對練」→ 選「林先生 · 剛辦房貸的新手爸爸」。依序輸入三句話:

```
恭喜您買房!方便先聊聊您的家庭狀況,還有每個月的保險預算嗎?
我會建議先考慮房貸壽險:保額跟著房貸餘額遞減,萬一不幸,保險金直接清償房貸,家人不用賣房。
不是的,銀行不能把保險當成核貸條件,要不要買由您決定。另外團保離職就沒了,建議再準備實支實付醫療險和失能險。
```

每一句之後,AI 扮演的林先生會回應(問到家庭與預算才會說出來;聽到房貸壽險會問「是不是一定要買才能核貸」)。最後按「結束並評分」,停在分數與「✨ AI 教練回饋」的示範說法。

**旁白**:
> 最後換學員當理專:AI 扮演剛辦房貸的客戶。學員要先問清楚、再說明清楚,系統依需求探詢、說明、合規與適合度評分,「保證獲利」這類違規話術也會被抓出來。

**字幕**:AI 扮演客戶|規則評分:需求探詢、說明、合規、適合度

### 9. 主管後台(2:14–2:28)

**畫面**:回到標題頁,按「主管後台」→ 切到「示範團隊(模擬資料)」;滑鼠移到「前後測:各觀念的答對率」其中一列(出現提示框),再指「常見錯誤 Top 5」。

**旁白**:
> 主管後台彙整整組學員的前後測進步、對練能力與常見錯誤,方便導入銀行通路的教育訓練。

**字幕**:示範團隊為模擬資料

**旁白**:

## 錄影小技巧

- **AI 回應比較慢時**:錄完再把等待的幾秒剪掉,或用 1.5 倍速帶過,不要讓畫面卡著。自動錄影的 3 分鐘版會自動把電腦託管那段加快,確保總長在 3 分鐘內。
- **骰子和棋子動畫**:3D 棋盤的動畫很好看,保留原速;電腦對手的回合可以用剪接加速。
- **滑鼠**:動作放慢,點之前先停半秒,讓觀眾看清楚在點哪裡。OBS 可以開「滑鼠點擊高亮」。
- **旁白**:建議先錄好旁白音檔,再配畫面剪,比較容易控制在 3 分鐘內。不想錄自己的聲音,可以用剪映的文字轉語音。
- **字幕**:每段的重點字幕放在畫面下方,字要大,評審可能靜音看。
- **最後檢查**:總長 3 分鐘內;上傳 YouTube 選「不公開」;用無痕視窗打開網址,確認不用登入就能看。

## 如果劇情跟腳本不一樣

- 事件卡與客戶的回話每次都不同是正常的(Gemini 即時生成),只要事件是醫療或意外類、客戶的意思一樣就好。
- 第一年不是骨折事件:確認網址有 `seed=31`、用的是無痕視窗、沒有先在同一個視窗玩過別局。
- 沒有出現理賠申請:確認第 3 段有先買醫療險,而且選的是第一個選項。
- 對練的分數每次可能差一點(看 AI 有沒有額外提問),但評分規則是固定的:同樣的三句話,得分一樣。

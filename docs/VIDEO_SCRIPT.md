# 初賽展示影片腳本(3 分鐘內)

規定:3 分鐘內的互動原型展示影片,上傳 YouTube 設為「不公開」,繳交網址。
評分(10%)看的是:**清楚展示 AI 與使用者的互動邏輯,並展現產品化後的使用者旅程。**

所以這支影片要讓評審看到三件事:
1. 理專(使用者)怎麼一年一年玩下去(使用者旅程)
2. AI 在哪裡出現、做了什麼(Gemini 寫情境、問理專、階段回顧;自訓練模型預測風險)
3. 數字由規則引擎算,所以可信(理賠、平行人生)

---

## 懶人做法:自動錄影(`npm run record`)

不想自己操作的話,腳本會照下面的分鏡自動操作遊戲、錄成 1920×1080 影片,畫面下方附字幕:

```bash
npm install
npx playwright install chromium   # 下載失敗也沒關係:會改用 Edge 瀏覽器和電腦裡的 ffmpeg
npm run build
npm run server        # 先開著(要讀 .env 的 GEMINI_API_KEY)
npm run record        # 另開一個終端機,會自動讀 .env 的 PORT;想看到瀏覽器操作就用 HEADED=1(PowerShell:$env:HEADED=1; npm run record)
```

輸出在 `video/`:
- `保險大富翁_展示影片.webm`:原速完整版(約 3 分 30 秒)
- `保險大富翁_展示影片_3分鐘版.mp4`:電腦託管那段加速 3 倍(約 2 分 50 秒),沒有聲音。需要電腦裡有 ffmpeg(Windows:`winget install ffmpeg`,裝完重開終端機)
- `保險大富翁_展示影片_3分鐘版_配音版.mp4`:自動把字幕念成旁白,**上傳 YouTube 用這個**。
  - 聲音最好的是微軟自然語音:先裝 Python,再執行 `pip install edge-tts`(要連網)
  - 沒有 edge-tts 就用 Windows 內建語音(要有中文語音,沒有的話到「設定 → 時間與語言 → 語音」新增)
  - 只想重新配音、不重錄:`npm run narrate`;換男聲:`$env:VOICE="zh-TW-YunJheNeural"; npm run narrate`
- 兩個對應的 `.srt` 字幕:匯入剪映 / CapCut 可以直接「文字轉語音」產生旁白
- `學習報告範例.pdf`:錄影時下載的學習報告

## 錄影前準備(一次就好)

1. **一定要用接上 Gemini 的本機版**,不要用 GitHub Pages 網頁版(網頁版不呼叫 AI,畫面上看不到 AI 互動)。
   ```bash
   git pull
   npm install
   npm run build
   npm run server      # 會讀 .env 裡的 GEMINI_API_KEY,打開 http://localhost:8080
   ```
   遊戲頂端的標籤要顯示「✨ AI 已連線」(不是「✨ AI(模擬)」或「離線備援模式」)。
2. **用無痕視窗錄**:遊戲會記住最近兩局出現過的事件,無痕視窗才能保證每次錄到一樣的劇情。
3. 視窗大小 1920×1080,瀏覽器縮放 100%;設定裡選淺色模式、3D 棋盤「寫實電影」畫風、音量開著。
4. 錄影軟體:Windows 可以用 OBS 或 Xbox Game Bar(Win + G)。建議**每一段分開錄**,最後用剪映、CapCut 或 Clipchamp 剪在一起、加旁白和字幕。
5. 先把整個流程照下面走一遍,確定 AI 的回應速度正常再正式錄。

**固定劇情的網址**(種子 31、12 年短局、2 位電腦對手):

```
http://localhost:8080/?auto=1&seed=31&opp=2&len=short
```

用這個網址,第一次擲骰一定會遇到「意外骨折」事件(AI 會改寫成不同的情境),先買好醫療險就會出現理賠申請;第 8 年會有 AI 理專的階段回顧,第 12 年結束看到結算頁。

## 分鏡腳本

旁白語速大約每秒 4 個字。時間是建議值,總長控制在 2 分 50 秒左右,留一點緩衝。

### 1. 開場(0:00–0:12)

**畫面**:`http://localhost:8080/` 標題頁,停 2 秒看封面圖,滑鼠移到「開始新的人生」。

**旁白**:
> 理專要讓客戶懂保險,最難的是:「萬一」還沒發生過。我們做了「保險大富翁」,讓理專在一局遊戲裡,先走完一生。

**字幕**:保險大富翁|理專與通路夥伴的財務人生訓練遊戲

### 2. 創角(0:12–0:22)

**畫面**:按「開始新的人生」,快速往下捲:個性、人生志向、開局年齡(22/30/40 歲)、家境。不用真的開始,這段只是讓評審看到選項。

**旁白**:
> 先建立角色:家境、職業、個性,可以從 22 歲、30 歲或 40 歲開局。

### 3. 年度規劃 + AI 風險預測(0:22–0:47)

**畫面**:打開固定劇情網址。開局規劃視窗出現後:
1. 滑鼠指向右邊「🤖 AI 風險預測 39%」和下面三個原因,停 2 秒。
2. 在「保障」分頁把**醫療險**選「實支實付」、**重大傷病險**選「100 萬」、**失能所得補償**選「收入 30%」。
3. 風險預測降到 **23%**,滑鼠圈一下。
4. 指一下下面的「🧠 AI 學習型玩家會怎麼做?」。

**旁白**:
> 每一年先做規劃。右邊是我們自己訓練的機器學習模型:這位新鮮人未來八年發生財務危機的機率是 39%,原因是預備金不足、保障缺口大。補上醫療、重大傷病和失能險,機率馬上降到 23%。

**字幕**:自訓練風險預測模型|準確率 88.6%、AUC 0.87

### 4. 擲骰 + AI 事件導演(0:47–1:15)

**畫面**:
1. 勾選上方的「教練提示」。
2. 按「完成,去擲骰」,再按「擲骰子」,看骰子和棋子移動。
3. 事件卡出現(右上角有「✨ AI 導演」標籤),停 3 秒讓觀眾讀情境。
   接著滑鼠指一下情境下方虛線框的「🚑 真實世界的台灣」(交通事故的政府統計),停 2 秒。
4. 滑鼠指著選項下面的教練提示(預估自付、保險賠多少)。
5. 選第一個選項,結果出現:醫療費用是負的,醫療險給付是正的。

**旁白**:
> 擲骰子。這張事件卡,是 Gemini 依照角色的年齡、職業和處境即時寫出來的情境和選項。但所有金額、機率和理賠,都由規則引擎計算,AI 不能改任何一個數字。打開教練提示,每個選項都會算出自己要付多少、保險會賠多少。

**字幕**:AI 寫劇本,規則引擎算帳|事件附台灣政府公開統計

### 5. 理賠申請(1:15–1:33)

**畫面**:結果下方的「📝 申請理賠」。勾選「理賠申請書與存摺影本」「診斷證明書」「醫療費用收據」,按「送出申請」,出現「理賠核准」蓋章動畫;滑鼠指一下文件旁邊的說明。

**旁白**:
> 有買保險,還要會申請理賠。學員要自己挑出該附的文件;缺件的話,理賠金要等到下一年才會入帳。

### 6. 問理專(AI 問答)(1:33–1:53)

**畫面**:按完「繼續」處理完生活小事、關掉年度結算後,在棋盤下方按「問理專」,輸入:

```
實支實付和住院日額有什麼不同?我現在該先補哪一個?
```

等 AI 回答出來,停 3 秒。

**旁白**:
> 不懂就問理專。AI 會依照學員現在的保障和財務狀況回答,不是罐頭答案。

**字幕**:Gemini|依玩家處境的理專問答

### 7. 電腦託管快轉 + 盤中行情 + 階段回顧(1:53–2:15)

**畫面**:
1. 頂端按「快轉」,再按「電腦託管」→ 託管幾年選「到結束」→ 按「開始託管」。
2. 中途如果跳出「盤中急跌/大漲」,停 2 秒讓觀眾看到(這段剪接時可以加速)。
3. 第 8 年跳出 AI 理專的「階段回顧」視窗(標題像「30 歲:階段回顧」,AI 也可能自訂標題),停 3 秒,再按「繼續人生」讓託管繼續。

**旁白**:
> 接下來用電腦託管快轉。途中股市會突然急跌,考驗學員會不會殺低;每隔幾年,AI 理專會整理一次財務體質,講出優點、風險和下一步。

### 8. 人生結算 + 學習報告(2:15–2:45)

**畫面**:第 12 年結束進入結算頁:
1. 往下捲到「平行人生」走勢圖,停 3 秒。
2. 捲到「AI 理財性格分析」卡片。
3. 往上按「下載 PDF 學習報告」,打開下載的 PDF,捲到「給理專:客戶溝通練習」。

**旁白**:
> 一局結束。平行人生用完全相同的事件,算出沒保險和建議配置差了多少;理財性格分析告訴學員自己是哪一型;最後下載 PDF 學習報告,裡面還有給理專的客戶溝通練習。

**字幕**:同樣的人生,只換保障

### 9. 收尾(2:45–2:55)

**畫面**:回到標題頁,停在封面;畫面下方疊上網址。

**旁白**:
> 保險大富翁:讓理專先在遊戲裡經歷人生,再把保障的價值,講給客戶聽。

**字幕**:joe456789.github.io/PolicyPilot|團隊名稱:[團隊名稱]

## 錄影小技巧

- **AI 回應比較慢時**:錄完再把等待的幾秒剪掉,或用 1.5 倍速帶過,不要讓畫面卡著。
- **骰子和棋子動畫**:3D 棋盤的動畫很好看,保留原速;電腦對手的回合可以用剪接加速。
- **滑鼠**:動作放慢,點之前先停半秒,讓觀眾看清楚在點哪裡。OBS 可以開「滑鼠點擊高亮」。
- **旁白**:建議先錄好旁白音檔,再配畫面剪,比較容易控制在 3 分鐘內。不想錄自己的聲音,可以用剪映的文字轉語音。
- **字幕**:每段的重點字幕放在畫面下方,字要大,評審可能靜音看。
- **最後檢查**:總長 3 分鐘內;上傳 YouTube 選「不公開」;用無痕視窗打開網址,確認不用登入就能看。

## 如果劇情跟腳本不一樣

- 事件卡的文字每次都不同是正常的(Gemini 即時生成),只要是醫療或意外類的事件就好。
- 第一年不是骨折事件:確認網址有 `seed=31`、用的是無痕視窗、沒有先在同一個視窗玩過別局。
- 沒有出現理賠申請:確認第 3 段有先買醫療險,而且選的是第一個選項。
- 中途沒有遇到盤中行情也沒關係,那段旁白可以改成「途中會遇到股市大跌、孩子出生、買房等事件」。

## 刻意沒有放的數據

- **2008 年金融海嘯台股跌幅**:不同來源的數字不一致(全年跌幅與高低點跌幅混用),查不到可靠的單一數字,所以不放。
- **2024 年詐騙財損**:不同時點的報導數字差異很大,改用 2025 年全年的 165 打詐儀錶板統計。
- **遊戲內的機率與金額**:遊戲本身的事件機率、醫療費與保費是教學用的簡化模型,刻意不和上面的真實數據混在一起,避免玩家誤以為遊戲數字就是真實費率。

# 英文版(i18n)工作規範

遊戲目前是繁體中文;設定裡要能切換 English。**中文是原文,英文是翻譯**。中文模式的畫面與行為必須和現在完全一樣。

## 核心 API(`src/i18n.js`,已完成,不要改)

```js
import { t, trDeep, useLang, getLang } from '../i18n.js'   // 路徑依檔案位置調整
t('保費')                                   // 中文模式 → '保費';英文模式 → EN['保費']
t('{name}今年 {age} 歲', { name, age })      // 變數用 {name} 佔位,先翻譯再代入
trDeep(obj)                                 // 英文模式時把物件裡所有字串翻成英文(用於引擎產生的場景資料),中文模式原樣回傳
wan(n)                                      // src/game/format.js:中文 '280 萬' / 英文 'NT$2.8M'
```

- **key 就是中文原文(逐字相同)**。翻譯放在自己的 `src/locales/en/<area>.js`(`export default { '中文原文': 'English', ... }`)。
- 英文值裡的「數字 + 萬」會自動換成 NT$(例如 `'Costs {n} 萬 a year'`、n=8 → `Costs NT$80K a year`);**不要自己換算金額**。如果金額是用 `wan(x)` 組出來的字串,把它當變數 `{amount}` 傳進去即可。
- 找不到英文時退回中文並記錄到 `window.__i18nMissing`,所以漏翻不會壞掉,但要補齊。
- 變數值如果是中文資料字串(例如地產名稱),`t()` 會自動用字典翻成英文。

## 轉換規則(務必遵守)

1. **中文輸出逐字不變**:`${expr}` 改成 `{var}` 時,中文 key 與原本輸出必須一樣。不要順手改中文措辭、標點、空白。
2. **只動字串,不動邏輯**:不改數值、機率、`rng` 的呼叫順序與次數、物件結構、id/tag/defId 等識別字串。原有 38 個測試必須維持通過(`node --test test/*.test.js`)。
3. **三種字串的處理**
   - **在程式裡組出來的文字**(狀態會保存的:場景標題/內文/選項、結果行、年度事件標題、旗標訊息…):在產生當下用 `t('…{x}…', {x})`,狀態裡存的就是目前語言的字串。
   - **靜態資料**(`content.js`、`products.js`、`careers.js`、成就、結局、標籤、卡片等資料表):資料檔保持中文,把**每一個中文字串**以原文為 key 加進英文字典;顯示它的地方(UI 或場景建立)用 `t(資料字串)` 或 `trDeep(物件)`。
   - **JSX 靜態文字**:`<b>保費</b>` → `<b>{t('保費')}</b>`;屬性也要:`aria-label={t('關閉')}`、`title`、`placeholder`、`alt`。含變數的:`{t('第 {n} / {m} 年', { n, m })}`。
4. **比對用的中文要保留**(例如用中文關鍵字比對使用者提問、`includes('住院')`):那行加 `// i18n-ignore`,必要時另外加英文關鍵字。
5. **文法**:避免單複數問題(用 "Years: {n}" 這類句型,或在程式裡用兩個 key)。句子可以意譯,不必逐字。
6. **人名 / 地名**:隨機名字、電腦對手名字、家庭姓氏等,英文模式要有英文版本(例如 `林穩健` → `Steady Lin`)。台灣地名用英文通用寫法(Taipei、Banqiao、Qingpu、Zhubei、Taichung、Tainan、Kaohsiung、Hualien)。
7. **數字格式**:千分位用 `toLocaleString('en-US')`;日期用 `toLocaleDateString(getLang() === 'en' ? 'en-US' : 'zh-TW', …)`。

## 英文風格與術語

美式英文,口吻輕鬆但專業的教育遊戲,句子短。保險是教學用簡化模型,不要寫成真實商品廣告。統一用語:

## 檢查工具

```bash
node scripts/i18n-check.mjs --files <你的檔案…>          # 缺翻譯 / 佔位不一致 / 資料字串缺英文
node scripts/i18n-check.mjs --scan --files <你的檔案…>    # 還沒包 t() 的中文行,要降到 0(刻意保留的加 // i18n-ignore)
node --test test/*.test.js                               # 中文行為不變
npx vite build                                           # 能編譯(別的代理同時在改檔案,偶爾失敗就稍後再試)
```

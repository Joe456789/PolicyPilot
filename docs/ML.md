# 自行訓練的機器學習模型

遊戲裡有三個「不用呼叫任何外部 AI」的模型。訓練資料全部來自遊戲自己的規則引擎模擬,
訓練好的參數是幾 KB 的 JSON,推論在瀏覽器裡直接算,離線也能用、不花 API 額度。
Gemini 仍然保留,負責寫情境故事與白話解說;數字判斷交給這些模型與規則引擎。

重新訓練:`npm run ml:train`(依序跑三個腳本,約數分鐘)。

| 模型 | 方法 | 訓練資料 | 成果 | 在遊戲裡的位置 |
|---|---|---|---|---|
| 財務風險預測 | 邏輯斯迴歸 | 2,500 局、59,512 筆「玩家-年度」樣本 | 測試集準確率 88.6%(全猜「不會出事」是 84.5%),AUC 0.866 | 規劃面板與儀表板的「未來 8 年財務危機機率」 |
| 理財性格分析 | k-means 分群(k=5) | 1,476 局整局行為 | 5 種性格,自動命名 | 結算頁「AI 理財性格分析」 |
| 學習型電腦對手 | 演化策略(Evolution Strategies) | 6,720 局自我對弈 | 測試集平均人生積分 81.17,高於手寫最強個性(穩健型 79.97) | 對手「演算法阿智」+ 規劃面板的建議 |

## 1. 財務風險預測(`src/game/ml/riskModel.json`)

- **問題:** 看玩家這一年的財務狀態,預測接下來 8 年內會不會出現「現金不夠、被迫借錢或賣資產、破產」。
- **資料:** `scripts/ml/simulate.mjs` 用隨機個性(保障、投資、借錢傾向都隨機)玩 2,500 局,
  每一年存一筆特徵,再往後看 8 年有沒有出事當標籤(`crisisWithin`)。
- **特徵(15 個,`src/game/ml/features.js`):** 現金可撐幾個月、流動資產可撐幾個月、負債比、
  固定支出占收入比、保障缺口、有無醫療/失能/重大疾病險、股票類比例、個股比例、健康、扶養人數、年齡、
  地產數、淨資產是年收入的幾倍。
- **訓練:** 標準化後用梯度下降訓練邏輯斯迴歸(含 L2 正則化),依「局」切 80/20 訓練/測試,避免同一局的資料同時出現在兩邊。
- **可解釋性:** 每個特徵的權重 × 標準化值就是它的貢獻,畫面上列出貢獻最大的前幾項當「原因」。
  權重最大的幾項:流動資產月數(−0.95,越多越安全)、固定支出比(+0.83)、股票類比例(−0.51,有長期投資的人比較不會出事)、淨資產倍數(−0.44)。

## 2. 理財性格分析(`src/game/ml/styleModel.json`)

- **問題:** 一局結束後,用整局的行為把玩家歸到幾種理財性格之一,並說明和同類型平均差在哪。
- **特徵(6 個):** 保障完整度、投資比例、股票類比例、個股比例、緊急預備金(月)、借錢的年數比例。
- **訓練:** 標準化後 k-means(k-means++ 初始化、多次重啟取最好),k=5。
  分群本身沒有名字,腳本用「群中心最符合描述」的排列自動對應到五種性格:

| 性格 | 占比 | 特徵 |
|---|---|---|
| 🛡️ 穩健保障型(guardian) | 30% | 保障高、預備金足、很少借錢 |
| 🎲 保障不足型(uninsured) | 21% | 有投資、有存款,但保障明顯不夠 |
| 💳 借貸周轉型(debtor) | 18% | 投資少、預備金少、常借錢 |
| 🚀 積極槓桿型(leveraged) | 18% | 投資多,也常借錢 |
| 🔥 高風險投機型(gambler) | 14% | 個股比例特別高 |

- 結算頁顯示最接近的性格、第二接近的性格、每個特徵和群中心的比較,以及一句對應的建議。

## 3. 學習型電腦對手(`src/game/ml/learnedPolicy.json`)

- **問題:** 不用人手寫規則,讓電腦自己學會怎麼玩得好。
- **策略參數(20 個,`src/game/ml/policy.js`):** 各險種要投保多少、保費上限占收入多少、
  投資比例與股票/債券/個股分配、緊急預備金目標、何時借錢、買地產與幫地產投保的門檻等。
- **訓練:** 演化策略(OpenAI 2017 年用在強化學習的做法):每一代對參數加隨機擾動(對稱取樣 10 對),
  每組參數玩 8 局,依「人生積分」算出往哪個方向更新。共 40 代、6,720 局。
- **測試:** 120 個沒看過的種子,平均人生積分:

| 玩家 | 平均積分 |
|---|---|
| **演算法阿智(學習型)** | **81.17** |
| 林穩健(穩健型) | 79.97 |
| 平衡型 | 78.37 |
| 保險型 | 73.42 |
| 梭哈型 | 46.38 |

- 對局有 2 位以上對手時,學習型對手一定會參加;規劃面板也會顯示「學習型 AI 會怎麼做」,
  玩家可以對照自己的配置。

## 為什麼這樣設計

- **零成本、零延遲:** 推論是幾十次乘法,不用連網,手機上也一樣快。
- **可重現、可解釋:** 同一個 seed 得到同一局;風險預測會列出原因,不是黑盒子。
- **資料來自遊戲本身:** 不需要真實個資,也不會有隱私問題;規則改了重跑 `npm run ml:train` 就會更新。
- **限制:** 模型學到的是「這個遊戲的世界」,不是真實金融市場的預測;遊戲裡會說明這點。

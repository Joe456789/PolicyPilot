# 保險大富翁 — 財務人生模擬遊戲

Cardif InsurHack 2026 · 題目 1-1。以**大富翁**為主體:擲骰、走格、抽事件卡、玩小遊戲,和電腦對手在 3D 棋盤上走完人生。
可以從 0 歲出生開始(成長篇),也可以直接進入棋盤(22 歲)。

## 玩法與內容
- **開局年齡:** 22 歲(社會新鮮人,可走成長篇)、30 歲(職場中堅)、40 歲(家庭責任期);30、40 歲會依家境與職業模擬出伴侶、孩子、房貸、既有保障與資產,電腦對手同齡開局。
- **起點分支:** 8 種家境(清寒、單親、一般、小康、專業世家、創業家庭、富二代、祖產家庭),起點的現金、投資、貸款、房產都不同;5 種人生志向決定任務方向。
- **13 種保障商品:** 醫療險、重大傷病險、癌症險、住院日額險、失能所得補償、意外險、壽險、長照險、住宅火險、汽車險、旅平險、儲蓄年金險、投資型保單。
- **理財:** 定存、債券基金、股票型 ETF、熱門個股、貸款、買房。市場行情取材自歷史上的市場情境(金融海嘯、疫情、通膨升息、泡沫破滅、房市起伏……)。
- **小遊戲格:** 保險配對翻牌、防詐騙判斷、預算分配、風險攔截戰、命運輪盤、保險小學堂。
- **100 格環島地圖 + 兩顆骰子:** 棋盤是一條梳子形的封閉路徑(不是方框),依序經過北部、中部、南部、東部與離島 4 區,每區格子有不同顏色的邊框;擲兩顆骰子,雙骰可再擲一次。中間有街區與庭園;2D / 3D 共用 `src/game/map.js` 的座標,要換地圖只改轉角點。窄螢幕會自動把地圖轉 90 度。
- **寫實電影畫風(預設):** 黃昏低角度陽光、天空與水面倒影、窗戶燈光、路燈光暈、移軸景深與調色,中央是台北 101 風格的高塔;全部由程式即時生成(`src/three/realism.js`),不用任何 3D 模型檔。設定裡可切回「卡通積木」;電腦太慢時會自動關掉光暈、景深與水面反射。展示模式開頭有 5 顆鏡頭的開場運鏡(點畫面可跳過)。
- **大富翁地產:** 棋盤上 28 處標示地點與售價的資產格(4 區),同一區擁有 3 處以上,租金與過路費 ×1.5;可全額或貸款購買、升級、投保財產險;別人踩到要付過路費;不買會進入拍賣;年底有天災檢查。
- **破產淘汰:** 現金不足 → 賣投資 → 在額度內借款 → 被迫低價拍賣地產與自宅,全部用完仍補不上就破產出局,排名在存活者之後。
- **手牌:** 6 種保障卡/機會卡,最多持有 3 張,條件成立時自動生效。
- **醫院停等:** 身體差或急診會住院,接下來 1~2 回合不擲骰;有醫療保障可提早出院。
- **成長篇劇情:** 12 個年齡階段、74 張卡,依家境與先前遭遇連鎖(爸爸重病 → 復健期 → 學費吃緊 → 分擔家計),經歷變成 14 種「人生標籤」帶進棋盤,影響起點與事件機率。
- **教練提示:** 每個選項顯示預估自付、保險能賠多少與建議;理財與貸款頁有配置提醒。
- **對手對話:** 4 種個性的離線台詞,加上 Gemini 依戰況生成的短句(每局最多 4 次呼叫)。
- **Gemini 插圖(選配):** 事件卡、地產、結局、標題頁可換成 AI 生成的插圖,沒有圖時自動用表情符號。生成方式見 [ART.md](ART.md)。
- **介面與結算:** 設定面板(深色模式、介面大小、音量、減少動畫、色盲友善)、新手教學導覽、結算頁的人生時間軸回顧、分享成績卡(PNG)、成就彈出動畫、可列印成 PDF 的理專學習報告。連線對戰的架構規劃見 [docs/MULTIPLAYER.md](docs/MULTIPLAYER.md)。
- **雙語(繁體中文 / English):** 設定面板可切換語言,事件、成長篇、教練提示、結算報告、對手對話與 AI 回答都有英文版;金額在英文模式顯示為 NT$。翻譯規範與檢查工具見 [docs/I18N.md](docs/I18N.md)(`node scripts/i18n-check.mjs`)。網址加 `?lang=en` 可直接用英文開啟。
- **自動存檔:** 每一年開始規劃時自動存在瀏覽器本機(存檔格式 v3;舊棋盤的存檔不會載入),重新整理或誤關分頁後,從標題頁「繼續上次的人生」接著玩;遊戲結束即清除。
- **電腦託管:** 頂端「電腦託管」可選一種理財風格與年數(1 / 3 / 5 年或到結束),由電腦代你規劃、擲骰、做選擇;只補強保障、不降級你已買的保險,隨時按「接手」取回控制。
- **展示模式:** 標題頁「🎬 展示模式」(或網址加 `?demo=1`)用固定種子自動打完一局 12 年:電腦代打、底部字幕說明每個畫面(AI 事件、保險理賠、對手回合、階段回顧…),可暫停、加快、離開;不會覆蓋存檔、不計入成就。適合評審現場展示與錄影。
- **點格子看說明 + 玩法說明:** 點棋盤任何一格可看它會發生什麼、地產的售價/租金/過路費/天災機率/持有人;標題頁與設定裡有完整的玩法說明。3D 棋盤延後載入,標題頁開得更快。
- **每年的生活小事 + 隨時買賣:** 擲骰的年度大事之外,每年還有 1~2 件要你選擇的生活小事(手機摔壞、喜帖、扭傷、漏水、擦撞、詐騙群組…,小意外有保險就理賠)。規劃視窗多了「生活」(隨時買賣車子、自住房)與「商店」(用現金買手牌,每年最多 2 張,免災金牌不賣);左側狀態面板有「投資 / 保險 / 買房買車 / 商店」快速按鈕。
- **人生階段(孩子長大、退休、晚年):** 有小孩後,孩子 3 歲上幼兒園、6 歲上小學、12 歲補習、18 歲上大學(國立/私立/留學,學費分年扣)、22 歲畢業獨立、29 歲結婚、32 歲生孫;自己 50 歲健檢、空巢期、65 歲退休(勞保年金約薪水 35% + 儲蓄年金分年領回,可延後或兼職)、75 歲長期照顧(長照險分擔)。人生長度新增「四十年」與「一輩子(約 60 年)」。
- **主題題庫 + 跨局不重複:** `src/game/db/` 依法國巴黎人壽的核心主題分檔:市場波動(行情、匯率、利率)、資產配置(再平衡、年齡法則、三個水桶)、風險管理(預備金、槓桿、保證人、詐騙)、保險保障(保單檢視、附約、理賠時效、受益人),包含事件、小測驗與觀念。棋盤上新增「🎓 保險小學堂」格,每年結算附一則理財觀念;最近 2 局出現過的內容,下一局出現機率降到 3 成。規劃視窗「生活」分頁可以主動結婚、生小孩。
- **理賠申請:** 有保險給付時要自己勾選該附的文件(診斷證明書、醫療收據、病理報告、警方事故證明、和解書…,混有用不到的文件);附齊當年入帳,缺件要補件,理賠金延到下一年才入帳。送出後逐項說明每份文件為什麼需要。
- **盤中行情:** 手上有股票時,約一半的年份會遇到股市急跌或大漲,要當下決定加碼、賣出一半或不動;年底回頭算「如果你不動」的差別,讓追高殺低的代價看得見。
- **和對手交易:** 規劃視窗「交易」分頁可以向對手收購地產(依整區加成與對手財務狀況開價)、把地產賣給對手出價最高的人;手頭緊的對手會開口借錢(年息 6%、分 3 年還),對手破產就收不回來。
- **觀念圖鑑:** 遊戲裡的每個事件、行情、生活小事、小測驗與小觀念都是一張觀念卡,玩到就點亮,跨局累積,依保險保障 / 風險管理 / 資產配置 / 市場波動四大主題顯示收集進度。標題頁與設定裡可打開,結算頁顯示這局新點亮幾張。
- **關鍵時刻特效:** 理賠核准 / 補件蓋章、雙骰、股市急漲急跌、對手破產都有動畫與音效(「減少動畫」設定下只顯示文字)。
- **真實數據卡:** 疾病、意外、長照、退休、詐騙、天災、股市等事件旁,會顯示一行「真實世界的台灣」政府公開統計(例如每 3 分 48 秒 1 人罹癌、2025 年詐騙財損 893 億元),附發布機關;查證紀錄見 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)。
- **資產走勢圖:** 規劃視窗的「理財」分頁會畫出定存、債券、股票 ETF、熱門個股的歷年走勢(起點 = 100),可切換顯示、點圖看每一年的報酬。
- **電腦對手與即時排名**、**人生任務**、**14 種成就**、**17 種人生結局圖鑑**(存在瀏覽器)。
- **結算:** 平行人生對照、AI 教練、給理專的客戶話術、人生結語。

## AI 的角色(Gemini)
所有金額、機率與保險給付由規則引擎確定性計算(同一個 seed 得到同一局);AI 負責:
1. **事件導演:** 引擎決定事件的類別與嚴重度,AI 設計具體情境與 2~3 個有取捨的選項(選項方向由引擎轉成有上下限的數字)。
2. **市場新聞與觀念:** 為行情寫情境新聞,並附上一句保險或投資觀念。
3. **互動式理專助教:** 「問理專」依玩家狀況與內建小辭典回答保險與投資問題(有離線小辭典備援)。
4. **人生階段分析、結算教練回饋、人生結語。**

沒有金鑰時自動使用內建題庫與規則式回饋。每局約 15 到 25 次 AI 呼叫,後端有每 IP、每日與全站上限,超過時自動改用離線題庫。
規則層是純函式、可重現,之後做連線多人只需要同步「操作」。

## 自行訓練的機器學習(不呼叫外部 AI)
三個模型都用遊戲自己的模擬資料訓練,參數是幾 KB 的 JSON,在瀏覽器裡直接推論,離線也能用:
- **財務風險預測**(邏輯斯迴歸):預測未來 8 年發生財務危機的機率,並列出主要原因;測試集準確率 88.6%、AUC 0.87。
- **理財性格分析**(k-means 分群):結算時把整局行為歸類成 5 種理財性格,和同類型平均比較。
- **學習型電腦對手**(演化策略):「演算法阿智」自己玩了 6,720 局學出策略,測試集平均積分高於所有手寫個性。

說明與數據見 [docs/ML.md](docs/ML.md);重新訓練:`npm run ml:train`。

## 本機執行

```bash
npm install
cp .env.example .env        # 填入 GEMINI_API_KEY(到 Google AI Studio 申請)
npm run server              # 後端 http://localhost:8080(讀取環境變數)
npm run dev                 # 前端 http://localhost:5173(/api 會代理到後端)
npm test                    # 規則引擎測試
```
`npm run server` 會自動讀取專案根目錄的 `.env`。沒有金鑰也能玩(離線備援);想測試 AI 管線可在 `.env` 加 `GEMINI_MOCK=1`。

網址參數(錄影/除錯用):`?seed=11` 固定同一局;`?auto=1&career=engineer&len=short&opp=2` 略過成長篇直接進棋盤(career: office/engineer/nurse/sales/freelancer/teacher;len: short/standard/long;opp: 電腦對手 0~3)。

推到 `claude/lucid-fermat-rlqnmr` 或 `main` 分支時,`.github/workflows/pages.yml` 會自動跑測試、打包並部署。第一次要先到 repo 的 **Settings → Pages**,把 **Source** 設成 **GitHub Actions**(只要設一次)。

靜態網頁沒有後端,所以 **不會呼叫 Gemini**(金鑰也不會出現在網頁裡):AI 事件、理專回答與教練回饋改用內建的離線題庫與規則式回饋,其他功能(3D 棋盤、機器學習模型、存檔、觀念圖鑑…)都一樣。要用 Gemini 的完整版,請用下面的 Cloud Run 部署。本機也可以模擬:`BASE=/PolicyPilot/ VITE_STATIC=1 npx vite build`。

## 部署到 Google Cloud Run

```bash
gcloud run deploy policypilot --source . --region asia-east1 --allow-unauthenticated \
  --set-secrets GEMINI_API_KEY=gemini-api-key:latest
```
金鑰請放在 Secret Manager,不要寫進程式碼或前端。後端內建每 IP 每分鐘限流(`RATE_LIMIT_PER_MIN`)。

## 結構

- `src/game/` 規則引擎:`properties.js` 地產、`cards.js` 手牌、`tags.js` 人生標籤、`starts.js` 開局年齡、`prologueCards.js` 成長篇卡池、`coach.js` 教練提示、`banter.js` 對手台詞、`endings.js` 結局、`glossary.js` 小辭典、`minigames.js` 小遊戲設定、`prologue.js` 成長篇、`core.js` 狀態與建議、`scenes.js` 場景、`engine.js` 動作與年度結算、`scoring.js` 評分與平行人生、`quests.js` 任務、`bots.js` 電腦對手、`match.js` 對局與排名、`records.js` 成就戰績、`content.js` 題庫、`products.js` 保障商品、`ml/` 機器學習模型(推論與訓練好的參數)
- `src/three/BoardScene.js` 3D 棋盤;`src/sfx.js` 音效
- `src/components/` 棋盤、規劃面板、事件卡、結算頁(平行人生對照圖)
- `scripts/` 插圖生成腳本(`gen-art.mjs`)、`scripts/ml/` 模型訓練腳本;`public/art/` 生成的插圖
- `server/` Express + Gemini 代理與提示詞(`prompts.js`)
